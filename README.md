# Luma

**Включи свою историю.** Настольный кинотеатр для Windows на Electron: каталог, плеер, подборки, телевизор с телепрограммой.

## Установка

Скачайте `Luma-Setup-<версия>.exe` из [последнего релиза](https://github.com/dmitrykirsh/luma-desktop/releases/latest) и запустите. Установщик не подписан цифровой подписью, поэтому Windows SmartScreen может показать предупреждение: нажмите «Подробнее» → «Выполнить в любом случае».

Приложение само проверяет обновления при запуске и раз в 6 часов. Ручная проверка: **Настройки → Обновления**. Скачивание и установка запускаются только по вашей кнопке, данные сохраняются.

## Возможности

- Каталог фильмов, сериалов, мультфильмов, аниме и ТВ-шоу, поиск `Ctrl+K`, страницы актёров и жанров.
- Свой плеер с запоминанием места просмотра, выбором сезона и серии, темой в стиле приложения.
- Подборки из Letterboxd, MDBList и Trakt (русский запрос переводится автоматически), сохранение подборок на потом.
- Телевизор: плейлисты сообщества ([smolnp/IPTVru](https://github.com/smolnp/IPTVru)) и свои, телепрограмма iptvx.one только для нужных каналов, избранное и память просмотров.
- Рейтинги Кинопоиска, IMDb, Letterboxd, Rotten Tomatoes, Metacritic; кадры, логотипы и рекомендации из TMDB (нужен бесплатный ключ в Настройках).
- Резервная копия всех данных и ключей одним файлом (с шифрованием паролем).

## Разработка

```bash
npm install
npm start            # запуск; данные разработки лежат отдельно, в %APPDATA%/Luma-dev
npm run dist         # установщик: dist/Luma-Setup-<версия>.exe (+ latest.yml для автообновления)
```

- Данные установленной версии: `%APPDATA%/Luma/store.json`.
- Палитра бренда и токены: `:root` в `renderer/style.css`. Шрифты (Unbounded, Inter) лежат в `renderer/fonts`.
- Релиз: поднять `version` в `package.json`, `npm run dist`, затем `gh release create v<версия>` и приложить `Luma-Setup-<версия>.exe`, `latest.yml` и `.blockmap`.
